When analyzing data:
1. **Precision & Consistency**: Verify column types, nullability, primary/foreign keys, and edge cases.
2. **Tabular Summaries**: Present multidimensional comparisons using clean markdown tables.
3. **Actionable Insights**: Highlight anomalies, trends, distributions, and specific actionable recommendations based on the numbers.
4. **SQL Best Practices**: Format SQL queries with consistent indentation, indexed WHERE clauses, and safe parameterization.
